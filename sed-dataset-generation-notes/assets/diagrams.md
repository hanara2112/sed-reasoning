## 2. Backward Construction Algorithm

```
┌─────────────────────────────────────────────────────────────────┐
│                    BACKWARD CONSTRUCTION                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   FORWARD VIEW (What we build):                                 │
│                                                                  │
│   ""  ──▶  "AB"  ──▶  "CDAB"  ──▶  "CDABEF"                    │
│       +AB      +CD          +EF                                  │
│                                                                  │
│   ════════════════════════════════════════════════════          │
│                                                                  │
│   BACKWARD VIEW (What the puzzle looks like):                   │
│                                                                  │
│   Initial: "CDABEF"                                             │
│                                                                  │
│   Transitions: CD→"", AB→"", EF→""                              │
│                                                                  │
│   Solution: [EF, AB, CD]  (reverse of construction)             │
│                                                                  │
│   "CDABEF" ──▶ "CDAB" ──▶ "CD" ──▶ ""                          │
│           -EF         -AB      -CD                               │
│                                                                  │
│   ════════════════════════════════════════════════════          │
│                                                                  │
│   KEY INSIGHT:                                                   │
│   If we BUILD by adding, we can SOLVE by removing in reverse    │
│                                                                  │
│   BUILD: ε → +α₁ → +α₂ → +α₃ → s₀                              │
│   SOLVE: s₀ → -α₃ → -α₂ → -α₁ → ε                              │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 5. BFS Solver State Space

```
┌─────────────────────────────────────────────────────────────────┐
│                      BFS STATE SPACE EXPLORATION                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│                          s₀ (initial)                            │
│                              │                                   │
│           ┌──────────────────┼──────────────────┐               │
│           │                  │                  │               │
│           ▼                  ▼                  ▼               │
│          s₁                 s₁'                s₁''             │
│           │                  │                  │               │
│      ┌────┼────┐        ┌────┼────┐             │               │
│      │    │    │        │    │    │             │               │
│      ▼    ▼    ▼        ▼    ▼    ▼             ▼               │
│     s₂   s₂'  s₂''     s₂'''s₂''''DEAD       DEAD              │
│      │                   │    END             END               │
│      │                   │                                      │
│      ▼                   ▼                                      │
│      ε ✓                s₃                                      │
│    GOAL!                 │                                      │
│                          ▼                                      │
│                        DEAD                                     │
│                         END                                     │
│                                                                  │
│   ═══════════════════════════════════════════════════════════   │
│                                                                  │
│   BFS explores level-by-level:                                  │
│   Level 0: {s₀}                                                 │
│   Level 1: {s₁, s₁', s₁''}                                     │
│   Level 2: {s₂, s₂', s₂'', ...}                                │
│   ...                                                            │
│   Until: ε found (success) or queue empty (no solution)         │
│                                                                  │
│   GUARANTEES:                                                    │
│   • Finds shortest path (optimal solution)                      │
│   • Complete (finds solution if one exists)                     │
│   • Deterministic (same puzzle → same solution)                 │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```
